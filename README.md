# The Crew RLCard Game

## Overview

The Crew RLCard Game is a simulation of The Crew card game, designed for research and experimentation in reinforcement learning. This project provides a framework for implementing various agents and testing their performance in the game environment.

## Project Structure

```plaintext
the-crew-rlcard-game
├── src
│   ├── game.py          # Main entry point for the game
├── requirements.txt     # List of project dependencies
└── README.md            # Project documentation
```

## Setup Instructions

1. Clone the repository:

   ```bash
   git clone git@github.com:michwoj01/The-Crew-RLCard-Game.git
   cd the-crew-rlcard-game
   ```

2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

## Usage

To run the bridge game, execute the following command:

```bash
python src/game.py
```
